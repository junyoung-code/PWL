# Windows 메모장 자동 저장 프로그램

Windows 메모장에서 변화가 감지되면 자동으로 파일을 저장하는 Python 프로그램입니다.

## 🎯 주요 기능

- ✅ 실시간 메모장 모니터링
- ✅ 저장되지 않은 변경사항 자동 감지
- ✅ 자동 저장 (Ctrl+S 전송)
- ✅ 멀티 윈도우 지원 (여러 메모장 창 동시 모니터링)
- ✅ 설정 가능한 체크 주기
- ✅ 로깅 기능

## 💻 사용 방법

### 기본 실행
```bash
python notepad_autosave.py
```

프로그램이 실행되면:
1. 백그라운드에서 메모장 창을 모니터링합니다
2. 변경사항이 감지되면 자동으로 Ctrl+S를 전송하여 저장합니다
3. 터미널에 실시간 로그가 표시됩니다

### 종료 방법
터미널에서 `Ctrl+C`를 눌러 프로그램을 종료할 수 있습니다.

## ⚙️ 설정

`config.json` 파일을 수정하여 프로그램 동작을 변경할 수 있습니다:

```json
{
  "check_interval": 5,      // 체크 주기 (초)
  "enable_logging": true,   // 로그 파일 저장 여부
  "log_file": "autosave.log" // 로그 파일 이름
}
```

### 설정 옵션 설명

- **check_interval**: 메모장 창을 체크하는 주기 (초 단위)
  - 기본값: 5초
  - 권장값: 3-10초 (너무 짧으면 CPU 사용률 증가)

- **enable_logging**: 로그를 파일에 저장할지 여부
  - `true`: 파일 + 터미널에 로그 출력
  - `false`: 터미널에만 로그 출력

- **log_file**: 로그 파일 이름
  - 기본값: `autosave.log`

## 📝 동작 원리

1. **창 감지**: Windows API를 사용하여 열려있는 메모장 창을 찾습니다
2. **변경사항 확인**: 창 타이틀에 `*` 표시가 있는지 확인합니다
   - 메모장은 저장되지 않은 변경사항이 있을 때 제목 앞에 `*`를 표시합니다
3. **자동 저장**: `*` 표시가 있으면 Ctrl+S 키를 전송하여 저장합니다

## 🔍 로그 확인

프로그램은 다음과 같은 로그를 생성합니다:

```
2026-01-28 12:00:00 - INFO - Notepad Auto-Save Program Started
2026-01-28 12:00:05 - INFO - 변경사항 감지: '*새 텍스트 문서.txt - 메모장'
2026-01-28 12:00:05 - INFO - 자동 저장 완료: '*새 텍스트 문서.txt - 메모장'
```

## ⚠️ 주의사항

1. **새 파일 저장**: 처음 생성한 파일(이름 없는 문서)은 "다른 이름으로 저장" 창이 열립니다. 
   - 파일 이름을 지정한 후에는 정상적으로 자동 저장됩니다

2. **대화상자**: "다른 이름으로 저장" 또는 "검색" 등의 대화상자가 열려있을 때 Ctrl+S가 전송되면 의도하지 않은 동작이 발생할 수 있습니다

3. **권한**: Windows API를 사용하므로 일부 보안 프로그램에서 경고를 표시할 수 있습니다

## 🐛 문제 해결

### pywin32 설치 오류
```bash
pip install --upgrade pip
pip install pywin32
python -m win32com.client.makepy.EnsureModule
```

### 프로그램이 메모장을 감지하지 못함
- Windows 메모장(`notepad.exe`)인지 확인하세요
- 다른 텍스트 편집기(Notepad++, VS Code 등)는 지원되지 않습니다

### 자동 저장이 작동하지 않음
1. 로그 파일(`autosave.log`)을 확인하세요
2. 메모장 창에 `*` 표시가 있는지 확인하세요
3. 프로그램을 관리자 권한으로 실행해보세요

## 🎮 사용 예시

```bash

  "enable_logging": true,
  "log_file": "autosave.log"
}
```

2초마다 체크하여 더 빠르게 자동 저장합니다.
